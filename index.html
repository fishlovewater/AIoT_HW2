04 — THE PROCESS

從問題到部署：CRISP-DM

把分析流程攤開，讓每一步都能被理解與重現。

01

商業理解

以新創支出與所在地預測利潤，找出資料中的關聯訊號。

02

資料理解

從指定 GitHub 取得 50 筆資料；檢查欄位、缺失值與重複資料。

03

資料準備

80/20 切分、random_state=0。州別 One-hot 編碼 drop='first'，僅在訓練集擬合。

04

模型建立

使用 sklearn LinearRegression；三項支出及兩個州別虛擬變數，以 California 為基準。

05

模型評估

計算測試集 R²、MAE、MSE、RMSE；以實際／預測及殘差圖檢查表現。

06

部署應用

匯出模型係數供網頁試算。資料與程式皆可下載，結果可重現。

原 Notebook 與本次模型的差異 ＋

原 Notebook 最後使用研發費用單變量模型並移除第 49 筆資料；本次依新增要求使用全部 50 筆、三項支出與州別的多元迴歸，保留異常點並以測試集評估。原文將標準化特徵直接輸入 100000，單位不一致；本網站使用原始美元特徵。R² 是解釋變異比例，並非準確率。含截距且保留全部州別虛擬變數時，VIF 無限大代表完全共線性，本次透過 drop='first' 修正。Notebook 的研發單變量 R² 約 0.947、移除資料後約 0.957，皆為樣本內擬合，不能與本網站的測試 R² 直接視為同類表現。
